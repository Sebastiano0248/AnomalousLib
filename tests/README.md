# Tests AnomalousLib

Tests simples per verificar que la llibreria funciona correctament.

## Fitxers de Test

- `test_constants.py` - Tests de constants i paràmetres
- `test_dataset_generator.py` - Tests de generació de datasets
- `test_data_analyzer.py` - Tests d'anàlisi de dades
- `test_preprocessing.py` - Tests de preprocessament
- `test_model_utils.py` - Tests d'utilitats de models
- `test_utils.py` - Tests d'utilitats generals
- `test_integration.py` - Tests d'integració

## Execució

Executar tots els tests:
```bash
python run_tests.py
```

Executar un test específic:
```bash
python test_dataset_generator.py
```

## Requisits

Els tests necessiten les dependències del `requirements.txt`.
